# Phase C — Gestures v2

**Date:** 2026-09-24  
**Status:** Implemented

| Gesture | Action |
|---------|--------|
| Pinch hold still ~0.45s until HUD `SNAP ✓`, then open | Screenshot → Desktop PNG (Quartz) |
| Pinch + move ↑/↓ | Volume (cancels pending snap) |
| 3 fingers hold ~0.55s (still; flicker-tolerant) | App Exposé (⌃↓) |
| 2-finger swipe | Spaces (unchanged) |
| 👍 hold | Mission Control (unchanged) |

**How to screenshot:** pinch thumb+index, keep still until preview shows `SNAP ✓ open`, then open the hand. Don't move up/down (that's volume).

Config toggles: `actions.screenshot`, `actions.app_expose`.

**Privacy:** Screen Recording for CV Desk / Terminal (screenshot). Accessibility for Exposé / Spaces / MC.
